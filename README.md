# POS Koperasi (Point of Sale)

Sistem Point of Sale (POS) modern yang dirancang khusus untuk kebutuhan Koperasi. Aplikasi ini mempermudah pengelolaan transaksi, inventaris produk, dan pelaporan keuangan.

## Fitur Utama

- **Dashboard Modern**: Visualisasi ringkasan transaksi dan status stok.
- **Manajemen Produk**: Kelola data produk dengan mudah.
- **Transaksi POS**: Antarmuka kasir yang cepat dan responsif.
- **Laporan Penjualan**: Cetak laporan harian, mingguan, atau bulanan.
- **Modern UI/UX**: Tampilan bersih dan responsif menggunakan CSS modern.

## Teknologi

- **Frontend**: HTML5, Modern CSS, JavaScript
- **Backend**: PHP
- **Database**: MySQL

## Instalasi

1. Clone repositori ini ke folder `htdocs` XAMPP Anda.
2. Impor database `dbpos_koperasi` (jika tersedia file .sql).
3. Sesuaikan konfigurasi database di `config/koneksi.php`.
4. Buka browser dan akses `localhost/pos_koperasi`.

## Lisensi

Proyek ini dibuat untuk keperluan pengembangan internal.
